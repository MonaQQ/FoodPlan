# FoodPlan 小程序发布说明

## 目录

- 工程目录：`miniapp`
- 入口页：`pages/index/index`
- 当前配置文件：`project.config.json`

## 首次运行

1. 打开微信开发者工具
2. 导入 `miniapp`
3. 没有正式小程序时，可先用测试方式预览

## 正式发布前要改的内容

1. 把 `project.config.json` 里的 `appid` 从 `touristappid` 改成你自己的正式小程序 AppID
2. 在微信公众平台补齐小程序名称、头像、类目和简介
3. 在公众平台完善隐私指引

## 提审前检查

1. 检查首页文案、菜品文案是否符合你想发布的中文展示内容
2. 检查自定义菜品新增、编辑、删除是否正常
3. 检查收藏、周计划、历史记录是否能正确保存在本地
4. 检查是否需要补充免责声明，例如“仅供参考，不构成营养或医疗建议”
5. 检查页面截图、图标、名称是否统一

## 当前实现说明

- 本项目不依赖后端服务
- 所有数据保存在微信本地存储
- 当前没有登录、支付、定位、手机号、文件上传等敏感能力

## 如果你准备正式上架

- 更贴近微信风格的中文文案校对
