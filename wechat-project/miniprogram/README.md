# FoodPlan 微信小程序版

这是基于现有 FoodPlan 逻辑单独整理出的微信小程序项目，目录为 `miniapp`。

## 打开方式

1. 打开微信开发者工具
2. 选择“导入项目”
3. 项目目录选择当前仓库下的 `miniapp`
4. `AppID` 如果暂时没有，可先使用测试号或开发者工具允许的体验方式

## 已实现功能

- 每日推荐
- 随机抽菜
- 菜谱筛选
- 收藏
- 自定义菜品新增、编辑、删除
- 一周计划
- 历史记录

## 说明

- 小程序数据使用本地存储保存
- 当前版本是独立小程序项目，不影响原有 Web 版和 Windows 分发版
- 如果后续要正式发布，需要在微信公众平台注册你自己的小程序 AppID
